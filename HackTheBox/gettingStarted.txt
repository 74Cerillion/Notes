Information Security:
    In a nutshell, the practice of protecting data from unauthorized access, changes, unlawful use,
        disruption, etc. 
    CIA Triad
    The Risk Management Process:
        Step 1. Identify the risks the business is exposed to
        Step 2. Analyze the risk. Determine their impact and probability. Map them to organizational
                policies, procedures, and processes
        Step 3. Evaluate the Risk. Rank and prioritize risks, make decisions on what to do about the risk:
                i.e. accept, avoid(change route), control(mitigate), or transfer(insure)
        Step 4. Dealing with Risk. Eliminate or contain risk as best as possible.
        Step 5. Monitor Risk. Constantly monitor for situational changes that could change the impact score

Connecting Using a VPN
    Two main types of VPNs: client-based and SSL.
        SSL uses the web browser as the VPN client
    Wy do we need a VPN?
        Obscures our browsing traffic and disguises our public IP address
        Some VPN service providers lie and log traffic.
            As such, never assume that the VPN is guaranteeing anonymity or privacy

Basic Tools:
    SSH - Port 22
    to use SSH:
        use the compromised cleartext credential username @ target IP
            $ssh Bob@10.10.10.10
    ----BANNER GRABBING----
    Netcat/ncat/nc: network utility for interacting with TCP/UDP ports
        Used to connect to shells
        Can connect to any listening port and interact with the service running on that port
            $netcat 10.10.10.10 22
                Connect to the server's SSH port
        This technique is called Banner Grabbing
            Using it identifies what service is running on a particular port.
        Can also transfer files between machines
    Tmux:
        Stands for Terminal Multiplexers
            Expands standard Linux terminal's features (things like having multiple windows w/n one
            one terminal and jumping between them)
        Installs with:
            $sudo apt install tmux -y
        Once installed, enter with:
            $tmux
        CTRL + B is the prefix to enter a command to Tmux
            (prefix) + C: opens a new window in tmux
            (prefix) + [number of pane you wish to view]: switches between panes
        SHIFT + % splits a window into vertical panes
        SHIFT + " splits a window into horizontal panes
    vim:
        text editor that's powerful and fast with hotkeys for navigation like vscode
        Some commands:
            vim <filename>: Open a file in vim
            i: enters insert mode where pressing keys now types
            esc: gets us out of insert mode where pressing keys will now do hotkey-type things
                x: cut character
                dw: cut word
                dd: cut full line
                yw: copy word
                yy: copy full line
                p: paste
            :: enters command mode
                :<#>: go to line number
                :w: write the file, save
                ;q: quit
                :q!: quit without saving
                :wq: Write and quit

Service Scanning
==========================================================================================================
First thing's first--- Identify the operating system and any services that are running
    We connect using the correct IP Address and Port Number and use a language that the service
    understands to try to get the service to perform unintended actions for us on the target system

Nmap:
    Scans the port range to search for open/available ports
    ---
    $nmap <target IP>
    ---
    By default, nmap will only scan the most common 1000 TCP ports unless arguments are specified
        -sC specifies nmap scripts should be Used
            There are default scripts, but you can also supply your own for more advanced functionality
            To specify your own script:
                $nmap --script <script name> -p<port> <host>
        -sV instructs nmap to perform version scan, fingerprinting services on target to Identify
                    protocol, application name, and version
        -p- tells nmap to scan comprehensive 65535 ports

Web Enumeration
==========================================================================================================
Web servers and applications provide a massive attack surface
    as such, web enumerationis critical
Once a web app is discovered, check to see if you can find any hidden files not intended for public access
    tools like ffuf or GoBuster perform this directory enumeration
    Sometimes, there will be hidden functionality that can be leveraged to access the web app or remote
                    code execution
GoBuster:
    allows for DNS, vhost, and directory brute-forcing as well as enumeration of public S3 buckets
